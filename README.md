# The Intern Named Kevin

> Congress is ready to regulate artificial intelligence, cryptocurrency and the entire internet, yet it still cannot turn a Word document into a PDF without summoning an intern named Kevin.

One sentence, 187 characters, and the whole roast: the people writing the rules for AI, crypto and the internet cannot perform the most basic file conversion in modern office life. The setup grants them sweeping authority over the future of technology, then undercuts it with a single mundane failure — summoning an intern named Kevin to do what a "Save As" menu has offered for twenty years. The punch lands on the last few words, and the joke is about power and competence, not abuse: the lawmakers are not villains, they are just the last people in the building who should be writing the rules for the machines.

## How to run

Requires Node.js 22 or later. No dependencies — standard library only.

```sh
node main.ts
```

This writes the entry line to `$MAKEFUN_OUTPUT_DIR/entry.txt` (defaults to `/output`), creating the directory if needed. The output has no trailing newline. Before writing, the script checks that the line is 1–320 Unicode code points, a single line, and not whitespace-only, and throws otherwise.

```sh
MAKEFUN_OUTPUT_DIR=/tmp/longroast-out node main.ts
```
